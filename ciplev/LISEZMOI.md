# Thème WordPress CIPLEV

## Installation
1. WordPress › Apparence › Thèmes › Ajouter › **Téléverser un thème** › choisir `ciplev.zip` › Installer › **Activer**.
2. À l'activation, le thème crée automatiquement :
   - les pages : Accueil, Le CIPLEV (Historique, Responsables, Mot du Président), Missions et actions, Organisation, Actualités, FAQ, Contact, Mentions légales ;
   - le menu principal et le menu du pied de page ;
   - le logo et les photos des responsables dans la Médiathèque ;
   - la page d'accueil statique et la page des actualités, les permaliens « /nom-de-la-page/ ».
3. Si une page a été supprimée par erreur : **Outils › Contenu CIPLEV** › « Installer le contenu manquant ».

## Personnalisation
**Apparence › Personnaliser › Options CIPLEV**
- Slogan retenu : liste des 9 propositions du document (ou slogan personnalisé).
- Texte d'accroche de l'accueil, adresse, téléphones, e-mail, horaires.
- Liens vers les réseaux sociaux (affichés dans le pied de page).

Les pages intérieures se modifient normalement dans l'éditeur de blocs.
Les encadrés jaunes « À compléter » signalent les informations manquantes.

## Publier une actualité
Articles › Ajouter : titre, texte, **image mise en avant**. Les 3 dernières apparaissent automatiquement sur l'accueil.

## Recommandé
- Langue du site : Réglages › Général › Langue du site › Français.
- Formulaire de contact : extension « Contact Form 7 » ou « WPForms », puis coller le code court dans la page Contact.
- Sécurité / sauvegardes : « Wordfence » et « UpdraftPlus ».
